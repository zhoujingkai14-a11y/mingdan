客户说“再加两张”，到底算修改还是增项？

备选：给接单设计师做了个开源报价确认工具

## 可复制正文

接设计单时，客户的一句“顺便再加两张”，可能是原来约定的调整，也可能变成两份新的交付。

我做了一个叫「明单」的工具，想把这件事讲清楚：

先把客户消息整理成能回看原话的需求清单；再按设计师自己的收费标准报价；客户确认这一版包括什么。后来有新增工作，就形成新版本，保留原先的约定。

图里是虚构的咖啡店开业订单：主海报和两项尺寸适配合计 ¥800；后续追加两张独立店内海报，演示设计师按个人价目表核对后，V2 合计 ¥1,600。这是示例个人价格，不是市场统一报价，也不是“客户一修改就加钱”。

AI 帮忙读消息，最终范围和金额还是由设计师核对。客户看的是交付、条件和总价，不需要研究你的内部价目表。

目前已开源，适合能自行部署、愿意尝试新工具的设计师或开发者。还没有公共在线试用；AI 需要自己的 API Key，调用费用另计。不会安装也可以先看截图和演示，告诉我这个流程哪里不符合你的接单习惯。

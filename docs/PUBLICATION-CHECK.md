## 发布范围

保留此前已审核并公开的仓库提交历史；本机开发工作区的私有历史未引入。具体文件、大小和 SHA-256 记录在 `release-manifest.json`，不记录清单文件自身的哈希。

源码、空数据库结构、虚构测试、Node 部署适配、抽象背景素材及虚构演示文档进入仓库。本机 API Key、实际订单、数据库、备份、日志、恢复密钥及此前托管平台标识不进入仓库。

检查包含：私密路径阻断、常见密钥模式、本机已有配置密钥精确比对、Git 对象和历史复核、素材及本地文档链接核对。工具不打印或记录密钥值。

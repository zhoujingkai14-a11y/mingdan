# Mingdan interactive demo

This branch contains the static, fictional-order demo for [Mingdan](https://github.com/zhoujingkai14-a11y/mingdan).

- Demo: https://zhoujingkai14-a11y.github.io/mingdan/
- Source application: https://github.com/zhoujingkai14-a11y/mingdan
- Source commit: 5c153fc83d450e6dab346d5f6739b70d1bde70f2
- No account registration, API calls, analytics, or persistent customer records.
- Confirmation is simulated in browser memory and resets on refresh.
- Real AI, accounts and customer links require the separately deployed application.
- The existing mouse interaction and reduced-motion support are retained.

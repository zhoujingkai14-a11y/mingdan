## 可复制正文

大家好，我做了一款叫“明单”的开源工具，想解决设计委托里一个具体问题：客户要求散在聊天中，原报价到底包括什么、后来追加了哪些工作，很容易说不清。

它把流程串成：客户消息 → AI 整理或手动填写 → 设计师核对与报价 → 客户确认具体版本 → 后续变更保存新版本。

目前重点是海报、视觉设计等中文接单场景，已有原话依据、个人价格表、漏算检查、账号隔离和独立客户确认链接。最终价格由设计师设定，AI 不擅自猜市场价；原先包含的正常修改，也不会直接变成新增收费。

README 中展示了一笔虚构订单：V1 的主海报和两项尺寸适配合计 ¥800；客户确认后新增两张独立海报，V2 合计 ¥1,600，V1 保持已确认。示例价格由演示设计师设置，字段人工准备，流程实际执行，没有用这个演示冒充模型理解效果。

这是 AI 辅助开发并持续人工迭代的作品，当前为 0.1.0-beta.1。Node.js 24 + SQLite，前端使用原生 HTML/CSS/JavaScript，没有第三方 npm 运行时依赖。可以先手动体验，再填自己的 DeepSeek Key。

还没有提供公共在线服务，需要自行部署；没有支付、订阅或客户真实身份核验，模型调用费用由使用者承担。当前需求理解质量仍需用不同真实文本验证。

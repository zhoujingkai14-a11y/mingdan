## 设置 GitHub 分享卡

下载 social-preview.png，打开[仓库 Settings](https://github.com/zhoujingkai14-a11y/mingdan/settings)，在 Social preview 中选择 Edit → Upload an image，上传封面并按页面提示完成保存。

GitHub 推荐 1280 × 640，支持小于 1 MB 的 PNG、JPG 或 GIF。提交图片到 README 不会自动设置这个仓库级分享卡；外部平台也可能缓存旧预览。见[官方设置说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview)。

## 介绍时保持准确

当前提供源码与自行部署方式，没有公共在线试用服务。自己的 API Key 调用可能收费；开源不代表模型调用免费。软件不提供支付、收款、订阅或客户身份核验，也不保证 AI 对任何文本都准确。

封面和演示价格是虚构案例中的个人设置。新增工作的费用要由设计师审核，包含的正常修改不能一律当成加钱。当前重点场景是中文视觉设计委托，不宣传为已经覆盖全栈开发全部计价需求。

普通反馈通过仓库 Issues 收集。想提供案例时使用虚构或脱敏内容；API Key、恢复密钥、客户链接和完整聊天不应公开。

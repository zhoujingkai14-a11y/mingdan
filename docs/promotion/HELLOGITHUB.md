## 项目简介

接设计订单时，客户常把交付内容、尺寸、时间和后续追加要求分散在多条消息里。明单把这些消息、设计师自己的价格表和客户确认的版本放到同一条流程中，方便双方说明“这一版包括什么，多少钱，后来改了什么”。

设计师可以接入自己的 DeepSeek 等兼容模型接口，整理带原话依据的需求候选，再人工核对并报价。客户只需打开专属链接查看交付范围、条件和金额，确认或提出调整意见。后续新增工作保存为新版本，旧报价与已确认内容继续保留。

## 值得介绍的特点

1. 需求候选可回看原话，缺失与冲突保留待确认，方便纠正 AI 理解。
2. 价格由设计师设定并审核，程序负责计算；包含的正常修改不自动当成新增收费。
3. 客户确认的是具体版本，客户页面不展示内部聊天和个人价目表。
4. 支持设计师账号隔离与本机持久化，无第三方 npm 运行时依赖；不接模型也能手动走完整流程。

## 使用门槛与边界

需要 Node.js 24。仓库提供启动配置、逐屏教程、截图、16 秒演示与测试版下载。Windows、Linux 自动检查已有通过记录；截图演示未使用真实模型，不能据此证明模型理解准确率。

当前界面和场景以中文视觉设计委托为主，不含支付、资金托管、订阅或客户真实身份验证。API 使用者自行提供 Key 和承担调用费用；正式公网部署、Docker 环境和不同真实需求仍需验证。
